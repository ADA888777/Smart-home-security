Smart Home Network Security and Anomaly Detection

Hybrid detection: explainable security rules combined with an Isolation Forest model, built for a smart-home LAN 192.168.10.0/24 with gateway 192.168.10.1.

Pipeline

flows → per-device per-minute features → security rules + Isolation Forest → risk engine.

Risk levels

NORMAL LOW MEDIUM HIGH CRITICAL — each with written reasons.
